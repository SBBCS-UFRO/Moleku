# Moleku Windows release

Moleku ships two Windows distribution assets, built from the same PyInstaller
onedir output (no Python, RDKit, or other libraries need to be installed
separately in either case):

- `Moleku-Setup-<version>.exe` — a proper installer (Inno Setup): Start Menu
  shortcut, optional desktop icon, "Add or remove programs" entry, and an
  uninstaller. This is the recommended download for most users.
- `Moleku-Windows.zip` — the portable onedir folder for users who prefer
  "unzip and run" with no installation step (e.g. locked-down machines).

## Local build

Use a dedicated build environment and the shared PyInstaller spec:

```powershell
$env:PYTHON = "C:\Miniforge3\envs\mcrg-build\python.exe"
scripts\build_windows_app.ps1
```

If `$env:PYTHON` is not set, the script falls back to `python` on `PATH`.

If PowerShell's default execution policy blocks the script (`Restricted`), run it via:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows_app.ps1
```

Recommended build environment:

```powershell
mamba create -y -n mcrg-build -c conda-forge python=3.11 rdkit pandas pillow numpy openpyxl reportlab pyinstaller
mamba activate mcrg-build
pip install customtkinter matplotlib
```

That produces:

- `dist\Moleku\Moleku.exe`
- `dist\Moleku\` (onedir folder with all dependencies)
- `dist\Moleku-Setup-<version>.exe`, if [Inno Setup](https://jrsoftware.org/isinfo.php) (`ISCC.exe`) is installed and found on `PATH` or in its default install location — the script builds the installer automatically as its last step. If Inno Setup isn't found, the script just prints a note and skips it; the onedir build is unaffected.

## Smoke test

Validate that the frozen build launches before packaging:

```powershell
scripts\smoke_test_windows_app.ps1 "dist\Moleku\Moleku.exe"
```

The smoke test starts `Moleku.exe`, checks that the process stays alive, then stops it.

## Zip packaging

Create the portable artifact with:

```powershell
Compress-Archive -Path "dist\Moleku" -DestinationPath "dist\Moleku-Windows.zip"
```

## Installer (Inno Setup)

The installer is defined in `packaging\windows\Moleku.iss` and built from
`dist\Moleku\` (run the local build first). Install
[Inno Setup](https://jrsoftware.org/isinfo.php), then:

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" /DMyAppVersion=1.1.1 packaging\windows\Moleku.iss
```

(`scripts\build_windows_app.ps1` runs this automatically when it finds
`ISCC.exe`, reading the version from `pyproject.toml`.) That produces
`dist\Moleku-Setup-<version>.exe`.

The installer defaults to a per-user install (no admin rights required —
important for shared/lab machines) but shows a dialog letting the user pick
"install for all users" if they do have admin rights. It installs to
`{app}`, adds Start Menu shortcuts, an optional desktop icon, and registers
a normal Windows uninstaller.

Test it locally with a silent install/uninstall round-trip:

```powershell
.\dist\Moleku-Setup-1.1.1.exe /VERYSILENT /SUPPRESSMSGBOXES /DIR="C:\temp\MolekuTest"
# ... verify C:\temp\MolekuTest\Moleku.exe launches ...
& "C:\temp\MolekuTest\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES
```

## Notes

- Neither the installer nor the portable zip is code-signed. Windows SmartScreen may warn on first run of `Moleku-Setup-<version>.exe` or `Moleku.exe` ("Windows protected your PC"); users can proceed via "More info > Run anyway". Signing with an Authenticode certificate (e.g. via `signtool`) would remove that warning and can be added later the same way `.github/workflows/release.yml` already conditionally signs the macOS build.
- The PyInstaller spec (`mcrg.spec`) already resolves a Windows icon (`images/moleku_simple_icon.ico`, generated by `scripts/generate_icons.py`) and only builds a macOS `.app` bundle when running on `darwin` — on Windows it produces the onedir folder directly, so no Windows-specific spec changes were needed.
